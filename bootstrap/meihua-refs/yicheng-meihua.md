# 梅花易数实战技法（一城法师183篇）

> 来源：一城法师梅花易数精讲系列183篇。核心：体用活变、转太极点、三要灵应。

## 核心要诀

> **体无定用，惟变是用；用无定体，惟化是体；法无定法，以心为法。**

1. 以理（义理）定旺衰，以礼读象，贴合实际
2. 三要灵应：耳、目、心皆可入卦
3. 克我者≠凶（官鬼克=工作用你）；比和≠吉
4. 空亡是象，旺相空出空填实，衰病空事情不成
5. 离=心=感情；坎=骗/变心；震=外遇；兑=缺损/第三者

## 起卦方法

### 时间起卦法
- 上卦：(年+月+日)÷8 取余
- 下卦：(年+月+日+时)÷8 取余
- 动爻：(年+月+日+时)÷6 取余
- 年数用地支数（子1丑2...亥12），月日用农历
- 卦数：乾1兑2离3震4巽5坎6艮7坤8

### 感情卦专用象
- 离 = 心 = 感情核心（离火旺=感情好，被克=受伤）
- 坎 = 骗子/小人/变心（坎水克离=被欺骗）
- 震 = 外遇（震在上=十有八九有外遇，震为动=往外走）
- 兑 = 缺损/第三者/争吵（兑为口=争吵）
- 艮 = 停止/停滞（艮=不想见面=分手）
- 变卦坎 = 出现第三者/变心
- 变卦离 = 对方心里想着你

## 体用论

### 体卦找法
- 问自己的事 → 体=我
- 问别人的事 → 体=那个主角（可能在互卦/变卦）
- 问物体 → 体=物体本身
- 问事件 → 体=推动事件的核心力量

### 关键原则
- **克我者≠凶**：官鬼克体=工作用你=有活干=面试能过
- **比和≠吉**：山地剥比和=群阴剥阳=凶
- **空亡≠没有**：可能还没开始，旺相空出空填实
- **体卦不一定在主卦**：主卦不像主角就转太极点

### 主互变
- 主卦 = 当前状态/主要矛盾
- 互卦 = 中间过程
- 变卦 = 最终结果/应期

## 转太极点

当主卦体卦不像测项时，找卦中最像主角的那个卦作为新体卦。

### 案例
- **手机进水**：离=手机不像主角→双艮=防水系统（止）→巽=吹风机→乾=圆满→能修好
- **钓鱼**：坎=鱼不像主角→艮=手+巽=鱼线+坎=鱼→人钓鱼能钓到
- **找钱包**：巽=钱包（纸钞）+互卦乾=金属扣→钱包特征明确，好找

## 三要灵应（外应）

测卦时周围一切皆可为外应：
- 辅助判断：加强或否定卦象
- 补充信息：卦象没有的信息
- 定应期：外应发生的时刻就是应期
- 例：占财运见窗外树叶飘（巽=风=飘忽）=财运不稳定留不住

## 感情卦判断步骤

1. 找体卦（主角）
2. 看离卦状态（离=心=感情核心）
3. 看克离的卦（坎水克离=受伤）
4. 看变卦（变坎=第三者）
5. 看震卦位置（震在上=外遇）

### 案例
- 水山蹇变泽山咸：女不想见（艮止），无真心（咸无心）=女嫌男烦
- 雷随变火雷噬嗑：震变坎=出现第三者，变坎=被绿，最后分手
- 测对方心里有没有我：离火生体=有真心；变卦离=想你；变坎克离=已变心

## 分类占断

### 失物占
- 体=失物本身，方向看体卦方位
- 体旺+能克=能找到；休囚死+被克=难找
- 变卦比和=物未动还在原处
- 例：巽为主（钱包）+互卦乾=金属扣=就在包里

### 考试占
- 体=考生，用=考场
- 离=文化=考得好；克体=有压力但能过
- 例：父亲考科目二，震=足=开车，震木旺艮土被克=能过

### 疾病占
- 坎=血液/肾/危险，坎旺=病重
- 巽=神经/风/抑郁，巽弱=神经类
- 乾=头/肺，被克=头肺问题
- 坤=脾，弱=脾胃虚
- 变卦比合=病未转移；变卦克体=病加重

### 求谋占
- 用生体=顺利有收获
- 体克用=主动出击能成
- 互卦=中间过程
- 变卦=最终结果

### 财运
- 巽=纸钞（财运看巽旺衰）
- 乾=大财（乾克巽=大坑=破财）
- 离=文化收入
- 兑=口舌收入（靠嘴吃饭）
- 例：麻将占巽旺克坎=能赢

## 吉凶与应期

### 显过
变卦与体比和但有小问题=有惊无险。例：水地比变山水蒙=亲密但蒙昧小问题，最终顺利。

### 应期判断
- 旺相空亡 = 出空填实为应期
- 用卦克体 = 应期在用卦旺相时
- 六爻动 = 主远主久
- 变卦旺时 = 最终结果

### 空亡理论
- **旺相空亡**：出空填实为应期（如木旺空，到春天出空）
- **衰病空亡**：事情不成/结束
- 空亡≠没有，是还没开始或力量不足
- 学了某技能=该技能不再空亡

## 年运判断

以水风井卦为例：
- 体巽木在亥月休囚=运势无大变
- 巽=纸钞休囚=求财受阻
- 乾克巽=工作被坑
- 农历四月后巽木得生=好转

## 高级技法

1. **一卦多断**：主卦断主要事，互卦断过程，变卦断结果
2. **六爻动**=涉及远方/长期事件
3. **看最旺五行**=该五行代表的内容最有力
4. **看动爻位置**=问题重点在哪方面
5. **梅花为体大六壬为用**：梅花快速定方向，六壬细断
