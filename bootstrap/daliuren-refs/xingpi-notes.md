## 九宗门（九种关系/玩法模式）

| 格局 | 含义 |
|---|---|
| 贼克 | 主动攻击、一方强势 |
| 比用 | 势均力敌、势均力敌谁也不让谁 |
| 涉害 | 过程曲折、有阻碍 |
| 遥克 | 远距离、异地、网调 |
| 昴星 | 暗中、偷偷摸摸 |
| 别责 | 不正常、非常规 |
| 八专 | 专注、单一、专情 |
| 伏吟 | 不动、老地方、老模式 |
| 反吟 | 反复、多变、来回 |

## 四课三传用法

1. 日干支定人：日干=本人，日支=对方
2. 四课定关系亲疏层次
3. 三传（初传/中传/末传）定过程与结果
4. 十二天将补细节：
   - 青龙 = 喜庆、正向
   - 朱雀 = 口舌、口、说
   - 勾陈 = 纠缠、慢
   - 六合 = 合作、和谐
   - 螣蛇 = 缠绕、怪异
   - 白虎 = 暴力、伤害
   - 太常 = 饮食、日常
   - 玄武 = 暗昧、偷情
   - 太阴 = 阴私、隐藏
   - 天后 = 女性、温柔
   - 天空 = 空、网调、文爱
   - 白虎 = 凶、伤
