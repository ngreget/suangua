# 大六壬占断解读

> **📚 来源**：本 Skill 项目维护文档，遵循 MIT License（见 [LICENSE](../LICENSE)）；参考传统：《大六壬大全》《御定直指玄妙六壬真铨》等公版古籍。
## 工作流程

### 1. 问事定题

- 明确用户问什么，不一问多占。
- 记录事项类别：财运/投资/事业/交易/出行/官非/疾病/婚恋/寻物/项目等。
- 明确时间范围：短期、半年、一年、多年。
- 记录人物：性别、角色、关系、是否本人问事。

### 2. 起课口径核验

必须确认或默认：
- 起课时间：优先用用户指定时间；未指定时用提问当前时间，标注时区。
- 时区：默认东八区北京时间。
- 历法：公历/农历、节气、月将、日干支、旬空。
- 月将、占时、昼夜贵人、贵人顺逆、四课三传。

### 3. 排盘

- 可尝试公开在线排盘页。
- 若网站验证码、登录、反爬、Canvas 图片、表单不可读，明确说明。
- 不得虚构盘面。
- 盘面读取失败时，要求用户上传高清截图或复制文字盘。

## 主断框架（依次分析）

### 四课
日干、日支、上神、下神，判断人事主客、内外、初始关系。

### 三传
初传发用、中传过程、末传归结，判断发展路径与结果。

### 天将贵神
贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后。

### 月将与旺衰
旺相休囚死、合冲刑害破、墓绝空亡。

### 类神
按事项取财、官、父母、兄弟、妻财、子孙、行人、病符等象。

### 课体
伏吟、返吟、连茹、涉害、遥克、昴星、别责、八专等，盘面可得才引用。

### 应期
以三传、日辰、冲合、旬空出空、墓绝冲开、用神动静推断。

## 输出结构

1. 简明结论
2. 盘面摘要（关键盘面，不堆砌术语）
3. 分项判断（四课→三传→天将→类神→应期）
4. 行动建议
