# 塔罗占卜解读

> **📚 来源**：本 Skill 项目维护文档，遵循 MIT License（见 [LICENSE](../LICENSE)）；参考体系：Rider-Waite-Smith 塔罗传统与现代塔罗教材。
## 工作流程

1. **明确问题**：用户想问什么就直接答。问题模糊时问1-2个澄清问题即可。

2. **选择牌阵**：根据问题复杂度选牌阵：
   - 快速问题 → 单张牌
   - 一般问题 → 三牌阵（过去/现在/未来 或 现状/障碍/建议）
   - 感情问题 → 关系牌阵
   - 深度问题 → 凯尔特十字
   - 用户指定牌阵就用用户指定的

3. **抽牌**：随机抽牌，记录每张牌的名称和正逆位。

4. **【重要】查找牌图**：抽完牌后，对每张抽到的牌，必须用图片搜索工具查找对应的 Rider-Waite-Smith 牌面图片：
   - 正位牌搜"韦特塔罗 XX 正位"
   - 逆位牌搜"韦特塔罗 XX 逆位"
   - 在解读中展示每张牌的图片，让用户直观看到牌面
   - 图片要和抽到的牌、正逆位对应

5. **逐张解读**：按牌阵位置解读每张牌：
   - 说明牌名、正逆位、位置含义
   - 正位：直接解读牌义
   - 逆位：解读为受阻、延迟、内化、负面表达

6. **综合解读**：
   - 看主导花色、重复数字、大牌出现密度
   - 串起整个牌阵的故事线
   - 直接回答用户的问题，给出明确判断

7. **行动建议**：给2-5个具体可执行的建议。

## 牌阵速查

| 牌阵 | 位置 | 适用 |
|---|---|---|
| 单张 | 1张 | 快速指引 |
| 三牌 | 现状/行动/结果 | 一般问题 |
| 时间流 | 过去/现在/未来 | 事情发展 |
| 关系 | 我/对方/关系现状/建议 | 感情 |
| 凯尔特十字 | 10张 | 深度复杂问题 |
