## 四元素小牌

| 元素 | 含义 |
|---|---|
| 权杖（火） | 强势、偏向控制、主动 |
| 圣杯（水） | 矜持、温柔、没经验、感情导向 |
| 宝剑（风） | 暴力、SM、伤害、疼痛 |
| 星币（土） | 追求快感、务实、实际、与钱有关、花钱搞 |

## 二十二张大牌要点

- 愚人 = 没经验、随便、大胆
- 魔术师 = 技巧多、会玩、掌控
- 女祭司 = 神秘、隐藏、冷淡
- 女皇 = 性感、享受、丰满
- 皇帝 = 权威、控制、强势
- 教皇 = 传统、规矩、传教士
- 恋人 = 爱情、选择、关系
- 战车 = 征服、前进、暴力
- 力量 = 掌控、温柔驯服
- 隐士 = 独处、自慰、隐藏
- 命运之轮 = 变化、时机
- 正义 = 平衡、对等
- 吊人 = 牺牲、倒立、另类
- 死神 = 结束、转变、深度
- 节制 = 和谐、平衡、融合
- 恶魔 = 欲望、束缚、SM、物质
- 高塔 = 突变、暴力、破裂
- 星星 = 希望、温柔、治愈
- 月亮 = 幻觉、潜意识、模糊
- 太阳 = 热情、开放、快乐
- 审判 = 觉醒、重生
- 世界 = 完成、圆满

正位=正向发挥，逆位=反向/过度/不足。
