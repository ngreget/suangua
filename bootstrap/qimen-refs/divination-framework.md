# 奇门遁甲占断解读

## 工作流程

### 1. 问事定题

- 明确用户问什么，不一问多占。
- 记录事项类别：财运/投资/事业/交易/出行/官非/疾病/婚恋/寻物/项目等。
- 明确时间范围：短期、半年、一年、多年。

### 2. 起局口径核验

- 起局时间：优先用用户指定时间；未指定时用提问当前时间。
- 阴遁/阳遁、局数、上中下元、值符值使、时家/日家/年家。
- 可使用 `scripts/qimen_cli.py` 排盘。

## 解盘框架（依次分析）

### 用神选择
按所问事项取用神：本人、对方、财、官、病、项目、股票等。

### 九宫落点
宫位、旺衰、空亡、入墓、刑冲。

### 八门
开、休、生、伤、杜、景、死、惊。

### 九星
蓬、任、冲、辅、英、芮、柱、心、禽。

### 八神
值符、螣蛇、太阴、六合、白虎/勾陈、玄武、九地、九天。

### 值符值使
全局主气与执行路径。

### 格局
三奇得使、门迫、击刑、入墓、反吟伏吟、空亡等。

## 与大六壬合参

大六壬主断、奇门复核：
- 两法一致 → 强信号
- 两法冲突 → 弱信号，需更多观察
- 分别列出大六壬判断和奇门判断，最后合参
