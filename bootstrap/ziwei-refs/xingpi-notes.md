## 十二宫功能分工（核心表）

| 宫位 | 功能 |

| 兄弟宫 | **你的性器官、同性关系、性能力** |
| 夫妻宫 | 你和对方怎么玩（手法/互动第一现场） |

1. 兄弟宫＋夫妻宫 = 你和他怎么玩（手法/互动）

- 禄=增加；忌=减少/缺失；权=强势；科=收敛

- 文昌化忌 = 骂人、dirty talk
