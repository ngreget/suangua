# 紫微斗数进阶技法（飞星派）

> 来源：水月紫微40篇实战课程。核心是禄转忌、大运忌、三财位、官禄飞化。

## 一、先天财富格局

### 三财位
- **财帛宫** = 现金流
- **兄弟宫** = 大财/量级更大的现金
- **田宅宫** = 不动产/最大财库

三个财位的禄忌关系决定先天财运。

### 命宫与财帛
- 命宫是财帛的官禄（气数位）
- 命宫化禄入财帛 = 与钱有缘，赚钱轻松开心
- 命宫化忌入财帛 = 与钱无缘，赚钱痛苦执着（财多身弱）

### 官禄与财帛
- 官禄最喜得权和科（升迁），得禄也不错（涨薪）
- 官禄禄入财帛 = 事业赚钱让人开心（三方禄主尽财）

### 生年忌在我宫vs他宫
- 我宫（命、福、官、财、疾、田）：关注向内，福禄自己得到
- 他宫（夫、友、子、父、兄）：关系不由自己，冲我宫损失更大，福禄跑到别人那里

## 二、发财大运

### 判定标准（同时满足）
1. 三财位至少一个实实在在得禄
2. 其他财位不被严重冲克
3. 田宅和兄弟得禄量级更大

仅一个财位得禄其他被冲 = 有财留不住，不等于发财。

### 大运忌看财运
- 忌在原局福德冲财帛 = 财帛有损
- 忌在原局子女冲田宅 = **破库（最严重）**
- 忌在交友 = 中等
- 忌在父母 = 较轻
- **原局被冲 > 大运被冲**

### 得禄与破财辩证
大运财帛得禄但兄弟和田宅被严重冲 = 因财招祸，得财后激进投资破大财。真正发财是三个财位都好，尤其田宅得禄。

## 三、禄转忌

### 原理
- 忌 = 100%投入和行动力
- 禄 = 趋向和希望
- 禄转忌 = 禄的能量转到某宫，该宫等同于也得禄
- 抓禄 = 某宫忌过来强制抓走另一宫的禄（被强迫）

### 三步分析
1. **落点**：大运禄落在原局哪个宫（田宅 > 兄弟 > 财帛 > 官禄 > 命宫）
2. **转机**：禄转到哪个宫（转到对宫=我宫得好处；转到他宫=好处给别人）
3. **抓禄**：哪个宫抓走了禄（我宫抓=好；他宫抓=被拿走）

### 最佳/最差
- 最佳：禄在他宫，禄转忌在我宫，抓禄在我宫
- 最差：禄在我宫，禄转忌在他宫，被他宫抓禄

## 四、大运忌一锤定音

### 三要素
1. **落点**：大运忌落原局哪宫，该宫主有问题
2. **忌冲**：大运忌冲到的本命宫位 = 这十年最伤的位置
3. **踩宫**：大运命宫踩到原局哪宫 = 该宫有变动能量

### 多项定一项原则
- 1-2项不利 = 可人力干预
- 3项以上 = 几乎不可避免
- 感情例：原局夫妻被忌冲 + 大运夫妻自化忌 + 大运夫妻化禄引动 + 妻田交易 = 4项 = 积重难返

## 五、配偶认识途径

### 原局看红鸾天喜所在宫线
- 命宫 = 自己主动
- 父母宫 = 长辈介绍
- 官禄宫 = 工作场合
- 财福线 = 兴趣场合
- 子田线 = 家庭/附近
- 子女宫 = 娱乐场合
- 兄友线 = 同辈介绍

### 大运精确判断
大运夫妻宫化禄入原局哪个宫 + 化禄之星属性：
- 武曲 = 事业场合
- 天同 = 轻松/朋友聚会
- 贪狼 = 娱乐/桃花
- 天梁 = 长辈介绍

### 直断技法
- A宫禄转到夫妻宫 = 配偶从A宫关系来
- 夫妻宫化忌入B宫抓B宫禄 = 配偶从B宫关系被我抓来

## 六、配偶颜值身材

### 三宫立太极（夫妻宫为我）
- 夫妻宫 = 配偶命宫（基本面貌）
- 官禄宫 = 夫妻之迁移（外在长相）
- 交友宫 = 夫妻之疾厄（身材高矮胖瘦）

### 主星看长相
- 太阴 = 温柔白净（嫦娥型）
- 贪狼 = 有性魅力（妖精型）
- 七杀 = 冷感肃杀（将军型）
- 太阳 = 帅气潇洒
- 太阳巨门 = 有距离感

### 加分
- 桃花星（红鸾天喜、咸池、贪狼廉贞）多 = 好看
- 昌曲 = 气质优雅
- 天魁天钺 = 身材高
- 天梁 = 身高往高拔

### 减分
- 煞星多、化忌多 = 矮胖
- 陀罗落陷 = 最影响颜值
- 零星 = 冷感但不丑

### 四化看
- 庙旺 = 较高；落陷 = 较矮
- 化禄 = 丰满；化权 = 高大；化科 = 斯文；化忌 = 矮小

## 七、官禄宫飞化看事业

### 前提：三方不能冲
命-官-财三方互冲 = 格局层次下降。

### 事业等级
1. **第一等**：官禄禄入父母宫（负极线）= 受长辈认可、易升迁、事业带来名誉
2. **第二等**：官禄禄入交友宫（兄友线）= 事业做大、利于扩大规模
3. **第三等**：官禄禄入福德或财帛（财富线）= 热爱事业、薪资高但层次稍低

### 官禄的负极线与兄友线
- 官禄负极线 = 官禄禄入交友（官禄之父母）
- 官禄兄友线 = 官禄禄入兄弟（官禄之疾厄）
- 禄入兄友线不如负极线，但外人看来差不多，只是更累

### 官禄忌入危险
- 官禄忌入父母 = 顶撞领导、事业不光明
- 官禄忌入疾厄冲父母 = 劳心劳力、官非、事业不稳

## 八、结婚应期

### 大运夫妻宫
- 三合煞多 = 感情不稳（不一定凶）
- 飞化为主，三合为辅
- 忌入迁移冲命 = 无缘
- 忌入子女冲田宅 = 不进家门
- 忌冲官夫线 = 小冲大凶

### 流年引动
大运夫妻飞禄/科/忌/权的年份连续出现 = 该区间是婚运。读书期间=恋爱稳定，工作后=婚运。

### 领证四条件（同时出现大概率领证）
1. 父母宫（文书位）红鸾天喜或引动
2. 大运夫妻科入流年夫妻
3. 子田线（房产）引动
4. 财帛有进出（女命彩礼入账，男命婚房支出）

## 九、破财大运

### 冲克力度
1. 最重：忌在子女冲田宅（破库）
2. 其次：忌在交友
3. 再次：忌在福德冲财帛
- 原局被冲 > 大运被冲

### 有出有进vs纯破财
- 大运田宅得忌+原局田宅被冲 = 有出有进（换房/资产转换），出多于进
- 大运仅被冲无进 = 纯破财

### 1/6/9/10宫不可冲
- 冲1（命）= 大财冲财
- 冲6（疾厄）= 财的疾厄冲财库
- 冲9（官禄）= 气数位冲气数位（与财无缘）
- 冲10（田宅）= 冲最大财库
