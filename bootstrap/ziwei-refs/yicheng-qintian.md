# 紫微斗数钦天派技法（一城法师）

> 来源：一城法师B站25篇教学。核心：宫星象三位一体、来因宫、离心破生年、串联反背。

## 一、四化本质

### 四化不是好坏，是谁让谁变成什么
- A宫干让B星变成禄/权/科/忌
- 关键问：谁让谁？变成啥样？
- 同样禄：贪狼禄=玩着学人缘好；天同禄=懒享受躺平
- 同样忌：天同忌=没欲望闷闷不乐；贪狼忌=玩心没了

### 能量来源
- 生年四化 = 老天给的先天配置
- 宫干自化 = 本宫自己的主动行为
- 离心 = 能量往外花
- 向心 = 能量往里收
- 四化方向打架 = 命运纠结处

### 阴阳四象
- 科+权 = 阳组（情绪、看不见的能量）
- 禄+忌 = 阴组（钱、行为、实际物质）
- 问感情多看阳组；问钱财多看阴组
- 能量感觉：科（温柔慢慢来要名分）→ 权（犟压人强迫）→ 禄（钱多变多）→ 忌（收起花掉执念）

## 二、自化与能量方向

- **自化**：本宫宫干让本宫星变化，代表本宫持续把老天给的能量往外花
- **离心**：往外发射、花掉对面能量、欲望索取消耗
- **向心**：从对面拿能量进来、得到加持
- **反背**：同宫同时有向心和离心 = 两边对着干、反复纠结消耗

## 三、星曜性格决定四化表现

| 星 | 五行 | 性格本质 |
|---|---|---|
| 贪狼 | 木水 | 欲望强、爱玩、人缘好、玩着学 |
| 天同 | 水 | 懒享受、孩子气、生殖泌尿 |
| 廉贞 | 火木 | 自律、桃花、化气为囚 |
| 紫微 | 帝星 | 使唤人、自私、围着自己转 |
| 天机 | 木 | 脑子快、变来变去、枢纽、求而不得 |
| 太阳 | 火 | 照亮温暖、吸引寂寞阴暗的人 |
| 太阴 | 水癸 | 私密阴柔、女性象 |

四化叠加在星原本性格上，不是独立事件。

## 四、串联与反背

### 串联
同组（都是禄忌 或 都是科权）几个宫同时花同一股生年四化 = 串联，一起发力，结论更强。

### 反背
向心（得到）和离心（消耗）同时存在 = 反背，矛盾冲突、反复。

### 替换
同宫位同时有B进来和C出去 = 替换，能量过手就走，来来回回、钱到手又花掉。

## 五、来因宫

### 定义
来因宫 = 命宫天干落在哪个宫。生年四化从这个宫发出，定一辈子命格主线。

### 故事主线
- 父母宫来因生年禄 → 父母让你事业有人缘
- 子女宫来因 → 和子女/下属缘分深
- 夫妻宫来因 → 姻缘是人生主线

### 河图体用关系
- **一六**（命、疾厄、福德）= 自己，身心中外
- **二七**（兄弟、迁移、父母）= 外部环境、外人、长辈
- **三八**（夫妻、交友）= 你选的人、合作伙伴
- **四九**（子女、官禄）= 不得不做的事、事业创业

体用：疾厄是命的体，福德是疾厄的用；田宅是财帛的体。

## 六、离心破生年

### 原理
生年四化 = 蓄水池；自化离心 = 往外开水龙头。
离心破生年 = 自化离心把同星生年四化花掉了 = 能量被消耗流失。

### 断凶步骤（以廉贞为例）
1. 找到生年四化那颗星
2. 看本宫或对宫有没有离心自化同一颗星
3. 离心方向 + 叠了哪些煞星 → 判断凶的程度
4. 廉贞忌 = 囚犯出狱、没约束；飞入弱势宫 = 狂妄没底线

### 平方破生年
一颗星同时有生年四化和自化四化（既得到又消耗），能量强但消耗也大。

## 七、星曜详解

### 天机星
- 枢纽+脑子快+变来变去+求而不得
- 天机在任何宫有自化（禄权科忌）→ 该宫"求而不得"
- 天机禄在夫妻 = 想结结不到的婚
- 天机入命 = 聪明、三心二意、纠结过度

### 紫微星
- 不化禄权科忌（不参与四化），偏情绪层面
- 紫微坐财帛 ≠ 富，只是围着钱转
- 紫微入夫妻 = 自私、要对方围着自己转
- 紫微化权 = 软刀子割肉，温柔地让人为自己服务
- 紫微入疾厄 = 身体固执傲慢

### 廉贞星
- 化气为囚 = 被道德法律规矩管着
- 自律带来人缘 = 知道什么时候说什么话
- 廉贞禄 = 非常自律、高道德标准
- 廉贞忌 = 放纵、没底线、不守规矩
- 廉贞+七杀/天刑 = 重口、暴力的桃花

### 贪狼星
- 欲望星（木水）= 求生欲、求知欲、财色食睡
- 贪狼自化忌 = 桃花变少、欲望收起来
- 贪狼自化禄/权 = 人缘极强、什么都想要
- 火贪、铃贪 = 遇机遇容易爆发

### 桃花星系统
- 不止廉贞贪狼：太阳（吸引寂寞阴暗的人）、天府（表面端庄背地反差）、天梁（荫蔽桃花）
- 桃花核心 = 人缘

### 巨门星
- 暗星 = 口舌、是非、隐瞒
- 巨门忌 = 因说话惹祸、判断失误
- 巨门权 = 争辩、控制言语
- 巨门禄 = 会说话、能表达
- 巨门科 = 表达得体、有文采

## 八、身体特征

### 星曜对应脏腑
- 木（天机、贪狼）= 肝胆、筋骨、脑子
- 火（廉贞、太阳）= 心脏、血液、眼睛
- 土（天府、天梁、巨门）= 脾胃、消化、肌肉
- 金（七杀、武曲）= 肺、大肠、骨骼
- 水（天同、太阴、破军）= 肾、生殖泌尿

阳 = 功能（力气）；阴 = 物质组织（肌肉器官）。

### 欲望强弱
- 贪狼自化禄/权/科 = 欲望强、主动出击
- 贪狼自化忌 = 欲望收起来、清心寡欲
- 生年忌/煞星叠进来 = 收得更厉害
- 命+福+疾同时有自化 = 身体和想法打架

## 九、专题技法

### 正缘生肖定法
1. 看夫妻宫有几颗星 → 每颗星对应可能生肖
2. 看生年四化飞入夫妻宫的星 → 锁定一个
3. 宫干四化再确认
4. 阴阳颠倒法：同路搞忌、同忌搞路（男女颠倒）
5. 多个宫同时指 → 综合判断

### 看性癖（子女宫为核心）
- 子女宫 = 人缘+合作+桃花+那方面关系
- 贪狼 = 欲望强；天府 = 表面端庄背地反差；紫微 = 索取型；廉贞七杀+天刑 = 重口
- 贪狼自化忌 = 欲望不强；紫微化权 = 完全不动享受型；太阳禄 = 外向主动；武曲化忌 = 物质不满足

## 十、实战案例对照

> 断盘时遇到相似结构，先对照下面案例找共同点。

### 案例一：物联网创业小哥（2024-11-19）
- 子女宫自化使官禄禄 → 有得力下属/创业伙伴
- 飞忌入迁移 → 外出有挑战、不宜乱跑
- 夫妻宫自化科消耗生年科 → 感情线有消耗
- 大运34~38岁夫妻宫走到父母宫科 → 晚婚
- 财帛向心得科权 → 事业有人帮衬
- 有反背 → 资金不够、矛盾
- **结论**：容易投资创业，26~27年投入大，28年发财，28年后持续向上

### 案例二：身体和心理矛盾的女粉丝（2024-11-20）
- 廉贞忌 → 身体有自律问题；过敏体质（血液免疫系统）
- 脑子和身体矛盾——脑子里不想，身体有需求
- 福德宫贪狼（欲望强）vs 疾厄宫离心忌 → 身体和想法打架

### 案例三：出轨对象分析（2024-01-24）
- 子女宫离心忌 → 桃花外遇
- 离心忌反回生年科 → 多了个科不平常 → 有第三者
- 法象串联：从廉贞串贪狼（都是女的）→ 第三者是女的
- 田宅离心忌 → 有家室的人
- 紫微化权 → 配偶控制欲强、不服软

### 案例四：正缘生肖定法（2024-01-25）
- 夫妻宫有贪狼/太阳/太阴/右弼等星 → 定生肖范围
- 生年四化飞到夫妻宫 → 锁定对应星的生肖
- 阴阳颠倒法：同路搞忌、同忌搞路（男女颠倒）
- 多个宫同时指 → 综合判断
- 注意：同八字的人不一定配偶生肖一样，同一颗星可能对应1/6概率，要多宫合看

### 案例五：来因宫与事业分析（2024-12-02）
- 来因宫父母 → 和父母/领导缘分深、事业受父母影响
- 子女宫自化使官禄禄 → 子女/下属带来事业运
- 文曲忌入迁移 → 网络工作头疼拧巴
- 父母宫生年禄 → 学业好、文凭高
